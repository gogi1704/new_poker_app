Подключи это до первого запуска — тогда локальный клуб настроится так, чтобы вход в панель не слетал при переключении офлайн/онлайн (единый адрес выше). Если уже запускал без этого — ничего страшного, просто единый адрес будет работать без автопереключения, и панель останется на отдельном локальном адресе (см. «Диагностика» ниже).

Турнир для синка

Дальше всё само: пока есть интернет, раз в минуту обновляются список игроков клуба (весь, не только записавшиеся на этот турнир) и выбранный турнир. Если сеть пропадёт — статус выше сам покажет, что делать.
